# GitHub Reflection

## 1. What is Git?
Git is a distributed version control system that helps track changes in files and manage project versions.

## 2. What is GitHub?
GitHub is a cloud-based platform that hosts Git repositories and allows developers to collaborate on projects.

## 3. What is the difference between Git and GitHub?
Git is a version control tool used locally on a computer, while GitHub is an online platform used to store and share Git repositories.

## 4. Why are commits important?
Commits save changes in a project and create a history of development, making it easier to track progress and restore previous versions.

## 5. Which Git command did you use the most and why?
I used `git commit` the most because it helped me save my work regularly and keep track of project updates.
